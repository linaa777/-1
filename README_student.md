# CampusFlow — материалы к практической работе №1

Ваша задача — не воспроизвести макет целиком, а провести его инженерный анализ и подготовить фундамент проекта.

До начала вёрстки:
- изучите все 3 экрана;
- прочитайте техническое задание;
- заполните `decomposition-template.md`;
- создайте собственный Git-репозиторий;
- самостоятельно создайте Vite-проект и настройте ESLint, Prettier и Stylelint;
- продумайте структуру директорий и семантический HTML-каркас.

Не переносите изображения экранов в проект как готовый интерфейс.
